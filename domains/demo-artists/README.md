# Artists Demo Data Product

This small dataset is useful for a quick functional check of Spark, Iceberg, and
Trino before running the larger taxi or industrial-energy pipelines.

```text
demo-artists/
├── dags/       # Optional manual Airflow workflow
├── data/       # Small version-controlled sample
├── spark/      # Genre summary transformation
└── tools/      # One-time loading and inspection utilities
```
